# Paylasim klasoru

Mac'teki hata metinleri ve ekran goruntuleri buraya konur, Windows tarafindan okunur.

En kolay yol, tarayicidan:
github.com/emrecamci1/pirinc-prototip -> `_paylas` klasoru -> **Add file** ->
**Upload files** -> dosyayi surukle -> **Commit changes**.

GitHub Desktop ile: dosyayi yerel `_paylas` klasorune kopyala, uygulamada
**Commit to main**, sonra **Push origin**.

Isi biten dosyalar silinebilir; burasi kalici arsiv degil.
